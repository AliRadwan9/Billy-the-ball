# Billy Ball

A fast-paced, arcade-style 2D game built in **Unity (C#)** designed for quick reflexes, dynamic physics-based movement, and web deployment.

---

##  Play the Game

The latest WebGL build is live and playable directly in your browser on itch.io:

https://3ali.itch.io/billy-the-ball

---

##  Features

- **Physics-Driven Ball Mechanics:** Responsive 2D movement and momentum control tuned for fluid maneuverability.
- **Dynamic Wave / Hazard Spawning:** Procedural obstacle/enemy spawning that scales in difficulty over time.
- **Score & High Score Tracking:** Live UI telemetry tracking current run score and session bests.
- **Optimized WebGL Performance:** Lightweight asset footprint and tuned canvas scaling for zero-install browser play.

---
---

## 🧠 What I Learned

- **2D Physics & Player Tuning:** Fine-tuning `Rigidbody2D`, drag, and velocity thresholds to balance snappy input response with predictable momentum.
- **Procedural Game Loops & Object Lifecycle:** Designing modular spawner systems, managing active game state transitions, and handling clean object pooling/destruction to avoid frame drops.
- **Event-Driven UI Telemetry:** Decoupling gameplay logic from UI updates using C# events/actions for score counters and state tickers.
- **WebGL Asset Optimization & Deployment:** Managing build sizes, texture compression settings, and canvas scaling constraints specifically targeting smooth performance in browser environments.
